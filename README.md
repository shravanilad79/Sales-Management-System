# 📊 Sales Management System

A simple and responsive **Sales Management System / Sales Pipeline Management System** built using **HTML5 and CSS3**. The project provides a dashboard-style interface for managing sales opportunities, tracking deals, monitoring customers, viewing forecasts, analyzing sales performance, and generating business reports.

---

## 📌 Project Overview

The **Sales Management System** is designed as a simple web-based sales dashboard where sales managers can view and organize important sales information from one place.

The system includes sections for:

* Sales Dashboard
* Sales Pipeline
* Deal Tracking
* Customer Management
* Sales Forecast
* Performance Analytics
* Sales Reports
* Sales Activities
* User Profile

The main dashboard provides an overview of sales, deals, revenue, targets, and conversion rate.

---

## 🎯 Objectives

The main objectives of this project are:

* To create a simple sales management dashboard.
* To organize sales opportunities according to pipeline stages.
* To track customer and deal information.
* To display sales performance data.
* To provide sales forecasting information.
* To present business reports in an easy-to-understand format.
* To create a responsive interface that works on different screen sizes.

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling, layout, responsive design and visual components
* **Vanilla JavaScript** – No external JavaScript framework is used
* **Responsive CSS Media Queries** – For mobile and tablet layouts

> **Note:** The current project is primarily a static HTML/CSS interface. The forms and displayed business data are presented as a front-end prototype and are not connected to a database or backend server.

---

## ✨ Features

### 1. 📊 Dashboard

The dashboard displays important sales statistics such as:

* Total Sales
* Total Deals
* Active Deals
* Won Deals
* Lost Deals
* Total Revenue
* Monthly Target
* Conversion Rate

It also contains recent deals, upcoming follow-ups, top sales representatives, and recent sales activities.

---

### 2. 🔄 Sales Pipeline

The sales pipeline organizes opportunities into different stages:

1. Lead
2. Qualified
3. Proposal
4. Negotiation
5. Won
6. Lost

Each deal displays information such as customer, amount, sales representative, and expected closing date.

---

### 3. 💼 Deal Tracking

The Deal Tracking section provides a table containing:

* Deal ID
* Customer
* Deal Name
* Sales Representative
* Amount
* Stage
* Probability
* Expected Close Date
* Status

There is also an **Add New Deal** form for entering new deal information.

---

### 4. 👥 Customer Management

The Customer Management section contains customer information including:

* Customer ID
* Customer Name
* Company
* Email
* Phone
* Industry
* Deal Value
* Customer Status

An **Add Customer** form is also provided.

---

### 5. 📈 Sales Forecast

The Sales Forecast section provides:

* Expected Revenue
* Forecast Revenue
* Closed Revenue
* Target Achievement
* Monthly sales forecast

The project includes monthly data from **January to December**, including targets, expected sales, actual sales and achievement percentages.

---

### 6. 🏆 Performance Analytics

The Performance Analytics section displays:

* Total Sales
* Number of Deals
* Won Deals
* Lost Deals
* Conversion Rate
* Average Deal Size
* Target Achievement

It also provides a sales representative performance table containing deals closed, revenue, targets and achievement percentages.

---

### 7. 📋 Reports

The Reports section provides different types of sales reports:

* Monthly Sales Report
* Deal Status Report
* Customer Report
* Revenue Report
* Sales Representative Report

These reports present sales information using structured tables.

---

### 8. 📅 Sales Activities

The Sales Activities section displays activities such as:

* Calls
* Meetings
* Emails
* Follow-ups
* Product Demonstrations

Each activity contains customer, representative, date, time and status information.

---

### 9. 👤 Profile Management

The Profile section displays sales manager information such as:

* Name
* Role
* Email
* Phone
* Department

An Edit Profile form is also included.

---

## 🎨 User Interface

The project uses a clean dashboard-style design with:

* Navigation bar
* Cards
* Tables
* Forms
* Status badges
* Sales pipeline columns
* Progress indicators
* Responsive layouts

The CSS includes responsive breakpoints for screens below 1000px and 700px, allowing the layout to adapt to tablets and mobile devices.

## ▶️ How to Run the Project

### Method 1 — Directly in Browser

1. Download or clone the project.
2. Locate the HTML file.
3. Double-click the HTML file.
4. It will open in your default web browser.

### Method 2 — Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `sales-management-system.html`.
3. Right-click the file.
4. Select **Open with Live Server** if the Live Server extension is installed.

## 📱 Responsive Design

The website is designed to adapt to different screen sizes.

On smaller screens:

* Dashboard cards become single-column layouts.
* Pipeline stages become vertically arranged.
* Forms change to one-column layouts.
* Profile information becomes vertically arranged.
* Navigation adjusts to smaller screens.
